# Pong Löve2d

Umsetzung von Pong in Löve2D

## Features

* Zwei voneinander unabhängig kontrollierbare Spieler. 
* Spieler 2 kann von einer simplen KI ersetzt werden.
* Kollision bei den Paddeln, der Decke und dem Boden.
* Scoresystem
* Bouncephysics beim Ball.
* Bei jeder neuen Runde ist die Startbeschleunigung des Balles anders.
